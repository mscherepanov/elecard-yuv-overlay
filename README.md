# elecard-yuv-overlay

Тестовое задание для компании «Элекард». Преобразование RGB-изображения в YUV420 и наложение его на видеоряд.

## Описание

Программа читает несжатую 24-битную BMP-картинку, преобразует её в YUV420 и накладывает на каждый кадр входного видео. Видео обрабатывается покадрово: весь файл не загружается в память. Результат записывается в отдельный YUV-файл.

Входное и выходное видео имеют планарный формат **I420**: плоскость Y, затем U и V. Сырые YUV-файлы не содержат размеров кадров, поэтому их нужно передать при запуске. RGB преобразуется по BT.601 с ограниченным диапазоном Y 16–235 и U/V 16–240; цветность усредняется по блокам 2×2.

## Возможности

- Чтение RGB24 BMP без сжатия, палитры и альфа-канала с учётом порядка и выравнивания строк.
- Наложение картинки в заданной позиции на все кадры I420-видео.
- Последовательная эталонная реализация преобразования RGB в YUV420.
- Многопоточное преобразование через `std::thread` для достаточно больших изображений.
- Ускорение вычисления Y с помощью SSSE3 на поддерживаемых x86-процессорах; при отсутствии SSSE3 используется скалярный код.
- Проверка размеров, границ наложения и неполного последнего кадра.

## Технологии

- **C++11**
- **CMake** (≥ 3.10);

## Требования

Установка зависимостей в Debian/Ubuntu:

```bash
sudo apt install build-essential cmake
```

## Сборка

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

## Запуск

```text
./build/yuv-overlay input.yuv image.bmp output.yuv width height [x y]
```

`width` и `height` — размеры кадра входного видео в пикселях. Необязательные `x` и `y` задают левый верхний угол картинки; по умолчанию `(0, 0)`.

Пример для видео 1920×1080 с наложением картинки в точке `(100, 100)`:

```bash
./build/yuv-overlay input.yuv image.bmp output.yuv 1920 1080 100 100
```

Размеры кадра и BMP, а также координаты наложения должны быть чётными. Картинка должна целиком помещаться в кадре. Наложение заменяет значения Y, U и V без прозрачности или смешивания. Входной YUV не должен быть пустым или содержать неполный кадр. Для результата используйте файл, который не ссылается на входное видео или BMP. После обработки программа выводит число записанных кадров.
