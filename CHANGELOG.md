# Changelog

Все значимые изменения в этом проекте документируются в данном файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [1.0.0] — 2026-09-30

### Добавлено

- Чтение несжатых RGB24 BMP с учётом порядка и выравнивания строк.
- Целочисленное преобразование RGB в планарный I420 по BT.601 с усреднением цветности в блоках 2×2.
- Наложение изображения на каждый кадр сырого I420-видео с заданными координатами.
- Покадровая обработка видео через CLI с проверкой размеров, ошибок ввода-вывода и неполного последнего кадра.
- Многопоточное преобразование через `std::thread` и ускорение вычисления Y с помощью SSSE3 на поддерживаемых процессорах.
- Тесты BMP, преобразования, наложения и обработки видео с запуском через CTest.
